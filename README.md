📥 Download (Für normale Nutzer)

Wenn du kein Entwickler bist und die Anwendung einfach nur nutzen möchtest, hast du zwei Möglichkeiten:

Option 1: Als ZIP-Archiv (Am einfachsten)
1. Klicke oben auf dieser Seite auf den grünen Button **Code**.
2. Wähle **Download ZIP** aus.
3. Entpacke die heruntergeladene ZIP-Datei auf deinem Computer.

Option 2: Über die Releases (Falls fertige Installationsdateien existieren)
1. Klicke rechts auf der GitHub-Seite auf **Releases**.
2. Lade dir dort die neueste Version herunter (z.B. eine `.exe` für Windows oder `.apk` für Android)
